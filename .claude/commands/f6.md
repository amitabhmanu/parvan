Run the preregistration's most important falsifier.

```bash
uv run parvan validate store
uv run parvan solve store --no-record
```

Then strip every `asserted`-tier edge and re-solve, reporting for each stratum of interest:

- the full bracket
- the attested-only bracket
- which attested edges carry it

Report it as the sentence F-6 exists to produce: *the checkable evidence alone supports X;
scholarly interpretation tightens it to Y.* If nothing survives, say so plainly — a network
that collapses without its asserted edges is formalizing the literature, not the evidence.
